# CompilersCourse2026

Репозиторий для написания компилятора языка PGL(Procedural General Language).

Сам по себе, этот язык и его компилятор являются доработками моего студенческого проекта, так что некоторая основа для проработки концепций уже имеется.

## Devlog

**Прошедшие стадии:**

1. Написаны лексер и парсер
2. Написание алгоритма построения AST-дерева
3. Написание визиторов (PrintVisitor, Interpreter, ScopeVisitor)

**Текущие задачи:**

1. Доработка грамматики
2. Замена классов на структуры(коими они и являются, честно говоря) и отказ от поддержки ООП

## Как собрать компилятор

```sh
make build
```

Бинарник появится в `build/compiler`.

## Как запустить программу на нашем языке

```sh
./build/compiler < examples/01_hello_world.txt
```

AST дерево записывается в `tree.txt`. Примеры находятся в папке [examples/](examples/).

## Как запускать тесты

Запуск тестов:

```sh
make test
make test SANITIZE=address,undefined
```

Очистка после тестирования:

```sh
make clean
```
